# 数据契约

材料试制记录以分号分隔的组分集合，按工厂计算批次数量和加权良率。

主测量 `yield_rate` 的单位为比例，主体字段是 `lot`，核算维度是 `plant`。`observation_id` 是文件内唯一观测编号，主体允许重复观测。数值只接受有限值；空单元格解析为 None，不能直接当成零。额外列不进入当前核算。

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `observation_id` | str | 必填 |
| `lot` | str | 必填 |
| `plant` | str | 必填 |
| `month` | int | 必填 |
| `items` | str | 必填 |
| `yield_rate` | float | 必填 |
| `size` | int | 必填 |
| `recipe_version` | str | 必填 |

时间字段 day、week、tick、hour、minute、cycle、start_day、reported_day、known_at、visible_at、opened、observed 均以各字段名所述的相对时间单位表示整数；不同字段并不必然代表同一种时间。缺少的登记码与浓度等信息保持为空。示例只表达产品数据结构，不能代替实际调查资料。

## 业务字段语义

items 为用分号分隔的组分名称集合，yield_rate 为 0 到 1 的良率，size 为被检件数。lot 对应一次试制，plant 为工厂，recipe_version 为配方版本；summary 的良率以 size 加权。

## discovery 口径与权重

`discovery` 命令把一个 lot 视为一个事务：同一 lot 的多条观测合并，items 内重复组分归一为集合；支持度只按去重后的批次数计数，`size` 不参与支持度。`size` 仅在验证期作为良率均值的权重（加权两样本比较），size 全为 0 的事务加权良率缺失，不进入数值分母。

发现集与验证集按 `month` 截开（默认 `month < 8` 为发现期，`month >= 8` 为验证期）。发现期只负责以最小支持批次与最大组合阶数筛选规则，规则集合进入验证期后冻结；验证期不再新增规则，只在同一工厂内比较规则命中批次与未命中批次的加权良率，并对全部“规则 × 可检验工厂”假设做一次 Benjamini-Hochberg 校正。跨厂只汇总覆盖与方向，不做跨厂合并检验，不允许事后挑选最显著的分厂结果。没有同厂可比样本（命中组或未命中组批次不足，或规则仅在一座工厂出现）的规则只能标记为共现发现，不输出良率关联结论。输出中的总体（跨厂合并）效应仅用于识别辛普森式冲突，不进入检验族。

## 合成数据的试验段设计

数据由 `tools/generate_observations.py` 以固定随机种子生成，可复现，全部为虚构内容。各组分承担不同的边界情形：

| 组分/情形 | 设计意图 | 预期 discovery 表现 |
| --- | --- | --- |
| `base` | 每个事务都出现的通用组分 | 厂内无未命中组，共现发现，不可检验 |
| `binder`、`coating` 及二者组合 | 三厂同方向正关联，且发现期与验证期都稳定 | 多厂 BH 显著的 `validated_association` |
| `fiber` | 几乎只在 P0 试用，验证期 P0 全量、其它厂为零 | 仅一座工厂出现，`cooccurrence_only`，不能称为协同 |
| `filler` | 集中在高基线工厂，厂内效应为负、跨厂合并为正 | 辛普森冲突标记，以厂内负效应为准 |
| `pilot` | 仅发现期 P1 试用 | 验证期支持为零，规则淘汰并留痕 |
| `novel_a`、`novel_b` | 验证期才出现的新组分 | 不进入冻结规则集合，仅登记为验证期新组分 |
| `L01`–`L16` 超长配方 | 每厂一条 17 组分事务 | 一阶即因支持不足剪枝，受阶数与候选预算约束，不枚举幂集 |
| 同 lot 重复观测、items 内重复组分 | 事务归一化 | 合并为一个事务，组分取并集，良率按 size 加权 |

输出中的结论字段均为相关性复验线索，不构成因果结论，也不构成配方更换建议。
